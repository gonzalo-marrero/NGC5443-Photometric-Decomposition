# NGC5443-Photometric-Decomposition

## 👥 Authors
- Gonzalo Marrero Ramallo  
- Fernando Barnés Sánchez  

## 📌 Description
Photometric decomposition of the galaxy NGC5443 using Imfit. The project includes 1D and 2D visualizations of the best-fit Sersic + Exponential model, calculates B/T and D/T ratios, and discusses the galaxy's morphology using NASA-provided data.

## 📊 Objectives
- Perform photometric decomposition of NGC5443  
- Identify the best-fit structural components of the galaxy  
- Visualize 1D and 2D fits alongside observational data  
- Compute bulge-to-total (B/T) and disk-to-total (D/T) ratios  
- Discuss morphological properties and compare with external datasets

## 🛠 Tools and Libraries
- **Imfit** (for photometric decomposition)  
- Python 3.x  
- NumPy, Matplotlib, Astropy (for data handling and visualization)
